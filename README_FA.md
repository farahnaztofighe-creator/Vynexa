# VynexaVPN — نسخه آماده استقرار

این بسته از فایل ارسالی ساخته شده و مسیر ذخیره‌سازی، وابستگی‌ها و تنظیمات محرمانه برای استقرار جدا شده‌اند. بخش‌های اصلی ربات، منوهای Inline، جریان خرید، قیمت‌گذاری، پرداخت کارت‌به‌کارت/کیف پول، رسیدها، مدیریت سفارش‌ها، ارجاع، ایموجی سفارشی و اتصال V2Route در کد اصلی حفظ شده‌اند. اطلاعات کاربران قبلی عمداً منتقل نشده‌اند.

## مهم: قبل از انتشار در GitHub
- توکن ربات و کلید API را داخل کد یا فایل‌های GitHub نگذار.
- در فایل قبلی، کلید V2Route به‌صورت مستقیم در سورس وجود داشت؛ آن کلید را افشاشده فرض کن و از پنل V2Route باطل/تعویضش کن.
- اطلاعات کارت و نام صاحب کارت را فقط در Environment Variables یا پنل تنظیمات خصوصی ربات وارد کن.
- فایل `.env.example` نمونه است و هیچ مقدار محرمانه‌ای داخلش قرار نده.

## متغیرهای محیطی
- `TELEGRAM_BOT_TOKEN` — الزامی
- `V2ROUTE_TOKEN` — برای ساخت سرویس خودکار V2Route
- `CARD_NUMBER` و `CARD_NAME` — جایگزین اختیاری اطلاعات کارت
- `VYNEXA_DATA_DIR` — مسیر داده‌های ماندگار؛ روی میزبان‌هایی که volume ماندگار `/data` دارند، مقدار `/data` بگذار.

## قیمت‌ها
قیمت‌های داخل منطق V2Ray حفظ شده‌اند. تنظیمات اولیه برای WireGuard و OpenVPN نیز اضافه شده؛ اگر فایل تنظیمات قبلی قیمت‌های دیگری داشته باشد، مقدارهای موجود اولویت دارند. قیمت‌ها به تومان هستند و منطق افزایش ۲۰٪ موجود در سورس حفظ شده است. بعد از راه‌اندازی، همه قیمت‌ها را در منوی مدیریت بررسی کن.

## اجرای محلی
```bash
python -m pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='توکن_ربات'
export VYNEXA_DATA_DIR="$HOME/vynexa-data"
python VynexaVPN_FadeHost.py
```

## محدودیت FadeHost
طبق مستندات رسمی FadeHost، میزبانی رایگان محدودیت منابع دارد: 256MB RAM، 0.25 vCPU، فضای `/data` تا 3GB و ترافیک مجموعاً 1GB در روز؛ بعد از عبور از ترافیک، برنامه برای 24 ساعت متوقف می‌شود. همچنین از هر حساب فقط یک اپ رایگان پشتیبانی می‌شود و گاهی باید از پنل/ایمیل تأیید کنی که برنامه هنوز استفاده می‌شود.

**نکته مهم‌تر:** مستندات FadeHost می‌گویند میزبانی پراکسی و تونل مجاز نیست. چون این ربات سرویس‌های VPN/پروکسی ارائه/مدیریت می‌کند، قبل از استقرار باید از پشتیبانی FadeHost تأیید بگیری؛ من پیشنهاد نمی‌کنم برای دور زدن این محدودیت تلاش کنی. برای اجرای واقعی این نوع سرویس، از میزبانی‌ای استفاده کن که صریحاً آن را مجاز می‌داند.

## استقرار از GitHub
این پروژه برای اجرای polling است و به وب‌سرور یا پورت ورودی نیاز ندارد. روی میزبانی سازگار:
- مخزن را به GitHub بفرست.
- `requirements.txt` را به‌عنوان وابستگی‌ها استفاده کن.
- فرمان اجرا: `python VynexaVPN_FadeHost.py`
- توکن‌ها و کارت را در Environment Variables بگذار.
- داده‌های تولیدشده را در volume ماندگار یا دیتابیس قرار بده؛ فایل‌های کنار سورس ممکن است در هر deploy پاک شوند.

## هشدار درباره قیمت‌ها
قیمت‌های پیش‌فرض صرفاً بر پایه اطلاعات موجود در فایل و زمینه پروژه بازسازی شده‌اند؛ قبل از دریافت پول واقعی، تمام پلن‌ها، مبالغ و عملکرد پرداخت را در ربات آزمایش کن.
